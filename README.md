# Credit Scoring Mini-Project

Мини-проект по задаче **кредитного скоринга**: предсказание вероятности дефолта клиента на основе табличных признаков.

## Описание проекта

Цель проекта — построить и сравнить несколько моделей машинного обучения для задачи **бинарной классификации**: определить, допустит ли клиент дефолт по платежу в следующем месяце.

В рамках проекта были рассмотрены как простые базовые модели, так и более сложные ансамблевые методы. Особое внимание уделено корректному разбиению данных, подбору гиперпараметров и сравнению качества моделей по метрике **ROC-AUC**.

## Используемый датасет

В работе используется датасет **Default of Credit Card Clients Dataset**.

Целевая переменная:
- `default payment next month` — факт дефолта клиента в следующем месяце.

Признаки включают:
- информацию о кредитном лимите;
- пол;
- образование;
- семейное положение;
- возраст;
- историю платежей;
- суммы выставленных счетов;
- суммы предыдущих платежей.

## Задачи проекта

В ходе работы были выполнены следующие этапы:

1. загрузка и предварительный анализ данных;
2. выделение признаков и целевой переменной;
3. разбиение выборки на обучающую и тестовую части;
4. обучение базовых моделей;
5. подбор гиперпараметров с помощью `GridSearchCV`;
6. сравнение моделей по метрике `ROC-AUC`;
7. анализ результатов и выбор лучшей модели.

## Использованные модели

В проекте были рассмотрены следующие алгоритмы:

- **Logistic Regression**
- **Decision Tree Classifier**
- **K-Nearest Neighbors**
- **Random Forest Classifier**

Основные библиотеки, использованные в проекте:

## Результаты моделей

| Model | CV ROC-AUC | Holdout ROC-AUC |
|------|-----------:|----------------:|
| Random Forest | 0.780087 | 0.782981 |
| Decision Tree | 0.760983 | 0.765998 |
| KNN | 0.742974 | 0.752532 |
| Logistic Regression | 0.719240 | 0.728864 |

## Лучшая модель

По результатам сравнения моделей наилучшее качество показала модель **Random Forest**.

Она получила максимальное значение `ROC-AUC` как на кросс-валидации (`0.780087`), так и на отложенной выборке (`0.782981`). Это говорит о том, что ансамблевый подход оказался наиболее эффективным для задачи кредитного скоринга на данном датасете.

Модель `Decision Tree` также показала достаточно сильный результат, однако уступила случайному лесу. `KNN` и `Logistic Regression` продемонстрировали более низкое качество, хотя логистическая регрессия может рассматриваться как хороший базовый интерпретируемый baseline.
